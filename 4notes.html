💻 OS & CPU Scheduling Notes

1. CPU Scheduling Basics

Burst Time (BT): Time required by a process for CPU execution.

Arrival Time (AT): Time at which the process arrives in the Ready Queue.

Turnaround Time (TAT): TAT = Completion Time - Arrival Time

Waiting Time (WT): WT = Turnaround Time - Burst Time

2. Key Scheduling Algorithms

FCFS (First-Come, First-Served): Non-preemptive, simple FIFO queue logic.

SJF (Shortest Job First): Minimizes average waiting time.

Round Robin (RR): Preemptive algorithm designed for time-sharing systems using a Time Quantum.
