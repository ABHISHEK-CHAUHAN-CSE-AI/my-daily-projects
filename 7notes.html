C Programming: Memory & Pointers Quick Sheet

1. Pointer Fundamentals

  • Pointer Variable: Holds the memory address of another variable.
  • Address-of Operator (&): Fetches the memory address of a variable.
  • Dereference Operator (*): Accesses the value stored at the target memory address.
int x = 10; int *ptr = &x; // *ptr evaluates to 10

2. Call by Reference (Swapping Logic)

Modifies original variables directly in memory inside functions:

void swap(int *a, int *b) { int temp = *a; *a = *b; *b = temp; }

3. Array & Pointer Relationship

  • An array name acts as a constant pointer to its first element: arr == &arr[0]
  • Pointer Arithmetic: *(arr + i) is equivalent to arr[i]
